## What these are

The **deployed forms** of the discipline stack: the text an agent actually loads
at runtime. The canonical, reviewed definition of a gate lives in
`gates/NN-<name>/GATE.md`. Where a gate has been built out, the GATE.md is the
source and the skill here is one of its forms. Where it has not, the skill here
is the whole of what exists — which is why the conductor's gate table marks most
rows "not yet".

`agents/` holds the custom reviewer agents the skills reference — `refuter` and
`mechanism-auditor` — so cross-references resolve inside this bundle.

## What the generator removes

Deterministic transforms, master → shareable:

1. The `## This environment` block, which holds machine-specific commands.
2. `Sources:` pointer lines, and any line referencing a private memory slug.
3. `[[wikilinks]]` flattened to plain text.
4. Private script paths and home directories genericized.
5. Trailing rules and blank lines trimmed.

## A rename is not done until every reader of the old name moves

On 2026-09-01 this bundle was found three months stale. One skill had been
renamed and the generator's own list still named the old one, so it printed
`skip <old-name> (no master)` and carried on — publishing a dead-named orphan
and omitting the live skill, silently, for three months. The generator now names
the current skill, and a skip is worth reading rather than scrolling past.
