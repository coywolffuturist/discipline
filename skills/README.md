# skills/ — CANONICAL. Edit here.

> Since 2026-10-01 these are the skills every machine runs, byte for byte. There are
> no private masters: `scripts/install.sh` copies each `skills/<name>/SKILL.md` to
> `~/.claude/skills/<name>/SKILL.md`, and `skills/agents/*.md` to `~/.claude/agents/`.
> Machine-specific facts belong in memory or `~/.config/discipline`, never in a skill.

The canonical, reviewed definition of a gate lives in `gates/NN-<name>/GATE.md`.
`skills/discipline/SKILL.md` is written from `CONDUCTOR.md` by the installer.
`agents/` at the repo root is a copy of `skills/agents/` for the plugin layout.
