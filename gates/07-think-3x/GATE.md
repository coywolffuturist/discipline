# Gate 07 — think-3x

    order:  07. DESIGN, after compile-it and before the prior is set. You cannot
            put a number on a design you have not yet chosen between.
    forms:  skill
    ruled:  the operator, 2026-09-01 — full moon. No second option worth naming,
            no gate.

---

## The read

**Think 1: the best idea. Think 2: red-team it. Think 3: the synthesis — and
build the synthesis, not Think 1.**

Think 2 carries two lenses. **karsholto** asks for the smallest brick that proves
the wall. **adversarial-inverse** is required only when the thing is a
cooperative-economic mechanism — a treasury, a fee, a slashing rule, an
eligibility test — and asks how a participant exploits it for gain at others'
expense.

The trigger was ruled by what the record showed. Across one day this gate fired
32 times and went N/A 5. Every honest firing named **a specific fork and why one
branch was taken**. The empty ones restated a decision that had no alternative —
deliberation theatre over a foregone conclusion.

So the trigger is the fork, not the difficulty. Hard work with one option is N/A.
Easy work with two real options is not.

## The intent

Build the red-teamed synthesis rather than the first idea, and leave a record of
the branch not taken so a later reader can re-open it.

## The forms

| form | what it is | when |
|---|---|---|
| **skill** | the read: three passes, the two Think-2 lenses, and the fork test for whether this gate applies at all | before building anything with a real alternative |

**No other form, and this is a ruling rather than a gap.** No hook: no pattern
can tell whether a second option was worth naming. No code: the same. No agent:
an agent without the context cannot know what the alternatives were, and
gate 18 already supplies independent review after the fact — this gate is about
the choice being made, not the result being checked.

A green check standing in for this judgement would be the ritual this suite
forbids, and inventing a mechanical form to make the gate look better-equipped
would be exactly the unjustified substrate gate 05 exists to refuse.

## Disproof

Refuted if a build passes this gate — a fork named, a branch chosen — and the
rejected branch turns out to have been obviously better on evidence available at
the time.

Watchable: every firing records the fork in a completion table, so the branch not
taken is written down and can be re-read against what happened.

**It has fired both ways in one day.** Choosing to guard a shell command by
parsing its text, over guarding it at the action point, was a fork this gate
should have caught and did not — the alternative was available and unexamined
until a third refutation forced it. Choosing to adopt an existing guard rather
than build a second was the same gate working.

**REVISIT** if the record shows firings that name a fork with no genuine second
branch — that would mean the fork test has become a formula, which is the failure
mode the N/A rate was ruled to fix.
